# 15-418 Project Website

Workload- and memory-aware scheduler for heterogeneous MCU cores  
Jason Tang and Catherine Li · Fall 2026

- Website: https://jasontxfei.github.io/15418-mcu-scheduler/
- Proposal: https://jasontxfei.github.io/15418-mcu-scheduler/proposal.html

The site is plain HTML with default browser styling. No CSS, JavaScript, dependencies, or build step.

## Edit

Edit `docs/index.html` for the homepage and `docs/proposal.html` for the proposal. Add later team-written reports to `docs/` and link them from the homepage.

Local preview: `python3 -m http.server 8000 --directory docs`.

## Hosting

GitHub repository Settings → Pages → Deploy from a branch → `main` → `/docs` → Save.

## Before submission

- Complete the weekly schedule in both HTML files.
- Confirm benchmarks and expand Background/Challenge details as needed.
- Add citations for the board and IPC examples you choose.
- Remove draft notes after reviewing the proposal.
- Use the browser Print → Save as PDF on the proposal page. Check the full PDF, including the project URL, and submit it to Gradescope as a group.

See the [course handout](https://www.cs.cmu.edu/~418/projects/project-proposal.pdf) for requirements. Publishing the website does not submit the proposal.
